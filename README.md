# LangGraph Lab

A hands-on learning repository documenting my journey of learning and building AI agents using LangGraph.

## Repository Structure

- Graphs/
  - Graph I: Basic LangGraph concepts
  - Graph II: Multiple operations and input handling
  - Graph III: Sequential agents
  - Graph IV: Conditional agents
  - Graph V: Loops and game-based workflows
- AI Agents/: Practical AI agent implementations.

## Tech Stack

- Python
- LangGraph
- LangChain
- Jupyter Notebook

## Purpose

This repository contains practical implementations, experiments, and progressively advanced workflows while exploring stateful AI applications and agentic systems.

More experiments and implementations will be added as I progress.
